# Echoes Git/Bash Prompt

Contains a install.sh script that can be executed to install everything needed.

Now it also shows the vpn ip when connected to a htb vpn.

## Install/update

One-line copy-paste installer/updater:

```bash
git clone -b colors-only --single-branch https://github.com/echoesofwhoami/echoes-bash-prompt.git && cd echoes-bash-prompt && sh install.sh && source ~/.bashrc && cd .. && rm -rf echoes-bash-prompt
```

Update the color var to display your favorite
